## 🚀 Các Tính Năng Đột Phá

### 1. 🖥️ Interactive Dev Terminal (Gõ Phím Kích Hoạt Tri Ân)
- Mô phỏng Terminal phong cách Linux / bash với âm thanh gõ **phím cơ cơ học (Mechanical Keyboard)** được tổng hợp bằng Web Audio API.
- Hỗ trợ lịch sử lệnh (Arrow Up/Down), gợi ý tự động (Autocomplete) và bảng lệnh gợi ý 1-click.
- Các lệnh độc quyền:
  - `git log --gratitude`: Hành trình học viên từ con số 0 đến ngày tốt nghiệp và tự tin vào doanh nghiệp.
  - `compile gratitude`: Biên dịch gói tri ân với *0 lỗi, 0 cảnh báo và 100% tình cảm*.
  - `sudo thank --all`: Kích hoạt pháo hoa và đặc quyền tri ân cao nhất tới Thầy Cô.
  - `cat letter.txt`: Đọc bức tâm thư xúc động của học viên gửi Người Thầy Lập Trình.
  - `skills --unlocked`: Vinh danh những phẩm chất và tư duy mà Mentor đã trao tặng.

### 2. 👨‍🏫 CodeGym Hall of Fame (Vinh Danh Giảng Viên & Mentor)
- Thẻ vinh danh các Thầy/Cô với bộ chỉ số "chuẩn Dev":
  - *Clean Code Rating, Bugs Crushed, Night-shift PR Reviews, Coffee Consumption*.
  - Tuyệt kỹ võ công (Superpower) & Câu nói bất hủ.
  - Tương tác: Thả tim ❤️, Gửi cà phê ảo ☕, Gửi lời chúc riêng 💌.
- **Tính năng đặc biệt**: Cho phép học viên tự thêm Thầy/Cô/Mentor của chính lớp mình vào Hall of Fame!

### 3. 💻 Trình Tạo Lời Chúc Chuẩn Dev & Xuất Thiệp 20/11 (Canvas E-Card Exporter)
- Bộ lời chúc viết bằng **7 ngôn ngữ lập trình phổ biến**:
  - `JavaScript / TypeScript`, `Java (Spring Boot)`, `Python`, `C# (.NET)`, `PHP (Laravel)`, `SQL`, `HTML/CSS`.
- Cửa sổ code phong cách VS Code với tính năng sao chép 1-click.
- **Bộ xuất thiệp điện tử Retina 2X**:
  - Tùy chỉnh Tên Thầy Cô nhận, Tên Học viên / Lớp gửi, Lời chúc và Bộ màu (Cyber Blue, Midnight Violet, Matrix Emerald, Warm Rose).
  - Xuất ra ảnh PNG chất lượng cao sắc nét tải về máy để gửi qua Zalo, Facebook, Teams, Slack.

### 4. 💌 Bức Tường Kỷ Niệm (Gratitude & Memory Wall)
- Nơi học viên lưu giữ những kỷ niệm thức khuya debug, chuyện vui phòng lab và lời cảm ơn.
- Lưu trữ cục bộ thông minh (`localStorage`), hỗ trợ lọc theo thẻ và thả tim cho các bài viết.

### 5. 🎮 Mini-Game: Hứng Hoa & Quà Tri Ân Thầy Cô
- Trò chơi tương tác điều khiển chiếc laptop CodeGym hứng hoa hồng 🌹, cà phê ☕, tim ❤️ và né tránh bọ 🐛.
- Có tính điểm, chuỗi Combo x2 x3, âm thanh phản hồi và cấp Chứng nhận Coder Tri Ân khi hoàn thành.

### 6. 🎵 Trải Nghiệm Âm Thanh Độc Bản
- Hệ thống âm thanh độc lập không phụ thuộc file ngoài: Âm thanh phím cơ gõ lách cách, âm thanh chuông chúc mừng, hợp âm Lo-fi chill thư giãn tự tổng hợp qua Web Audio API.

## 🛠️ Công Nghệ Sử Dụng

- **Frontend Core**: React 19, Vite 6, Tailwind CSS v4.
- **Icons & Graphics**: Lucide React, HTML5 Canvas API (High-DPI 2X Card Rendering).
- **Effects & Audio**: Canvas Confetti, Web Audio API Synthesizer (Zero MP3 dependencies).
- **Responsive**: Tương thích mượt mà trên cả Desktop, Tablet và Mobile.

## 📦 Hướng Dẫn Cài Đặt & Chạy

### Cách 1: Chạy nhanh bằng file start.bat (Khuyên dùng trên Windows)
- Nhấp đúp chuột vào file `start.bat` trong thư mục này. Trình duyệt sẽ tự động mở trang web!

### Cách 2: Chạy bằng dòng lệnh
```bash
# Cài đặt thư viện (nếu chưa cài)
npm install

# Khởi chạy server phát triển
npm run dev

# Hoặc build production
npm run build
npm run preview
```
